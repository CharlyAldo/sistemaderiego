¿POR QUÉ ES IMPORTANTE?

Ventajas del proyecto

Una solución práctica para usar el agua de manera responsable.

💧

Beneficios

  • Ayuda a reducir el desperdicio de agua.
  • Favorece el crecimiento saludable de las plantas.
  • Disminuye la necesidad de riego manual constante.
◎

Utilidad

Puede utilizarse en huertas escolares, familiares o comunitarias, adaptándose al tamaño del cultivo y a sus necesidades.

⚠

Problemas que resuelve

  • Riego excesivo o insuficiente.
  • Pérdida de tiempo en tareas repetitivas.
  • Dificultad para mantener la humedad adecuada.

DISEÑO, CONSTRUCCIÓN Y PRUEBAS

¿Cómo se elaboró?

El proyecto integra electrónica, programación y cuidado del medioambiente.

El equipo investigó las necesidades de una huerta y diseñó un sistema capaz de activar el riego cuando la tierra necesita agua. El prototipo se monta, programa y prueba para comprobar que sus componentes funcionen de forma coordinada.

🔧 Materiales y componentes

  • Arduino Uno (o controlador equivalente)
  • Sensor de humedad del suelo
  • Módulo relé compatible
  • Bomba de agua de bajo voltaje
  • Mangueras y goteros
  • Fuente de alimentación adecuada
  • Cables, protoboard y caja protectora

Los componentes pueden variar según el diseño final del equipo. Mantén el agua separada de las conexiones eléctricas y utiliza alimentación adecuada.

01

Investigación y diseño

Se identificó la necesidad de riego y se elaboró un esquema del sistema.

02

Montaje

Se conectaron el sensor, el controlador y el mecanismo de riego siguiendo las recomendaciones de seguridad.

03

Programación

Se estableció un umbral de humedad para decidir cuándo activar o detener el riego.

04

Pruebas y mejoras

Se probaron las lecturas del sensor y el flujo de agua, ajustando el sistema según los resultados.

¿CÓMO FUNCIONA?

Del sensor a la planta

1

Detectar
El sensor mide la humedad del suelo.

2

Decidir
El controlador compara la lectura con el umbral configurado.

3

Regar
Si hace falta agua, activa la bomba; al alcanzar la condición definida, la detiene.
