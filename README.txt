PROYECTO: RIEGO AUTOMÁTICO DE HUERTAS
====================================

Archivos:
- index.html
- css/styles.css
- js/script.js

Cómo probar:
1. Descomprime la carpeta.
2. Abre index.html en un navegador.
3. Necesitas conexión a Internet para cargar las fotografías remotas y las fuentes de Google Fonts.

Personalización:
- Sustituye "Nombre del estudiante 1..." por los nombres reales del grupo.
- Actualiza las responsabilidades de cada estudiante.
- Puedes reemplazar los emojis de las tarjetas por fotografías autorizadas.
- Cambia los materiales para que coincidan con el prototipo real.
- El año y los datos institucionales se pueden editar en index.html.

Publicación en Vercel:
1. Sube la carpeta a un repositorio de GitHub.
2. Entra a https://vercel.com/ e importa el repositorio.
3. Como es un sitio estático, no requiere comando de compilación ni directorio de salida especial.
